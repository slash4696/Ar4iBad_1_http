# Visual Story

Личное фотопортфолио с галереей нейрофотосессий, заявкой на услугу за 490 ₽, регистрацией, личным кабинетом и закрытой админ-панелью.

## Что уже работает

- Главная страница с адаптивной галереей, просмотром фотографий, скачиванием примеров и анимациями с поддержкой `prefers-reduced-motion`.
- Форма заявки сохраняет контакт, сообщение и согласие в PostgreSQL. Для вошедшего пользователя заявка также появляется в личном кабинете.
- Регистрация и вход по электронной почте и паролю. Пароль должен содержать не менее 10 символов.
- Админ-панель `/admin`: просмотр заявок и изменение их статуса. Для первого входа создайте администратора командой ниже.
- Внешняя оплата, подтверждение почты и отправка уведомлений пока не подключены. Кнопка за 490 ₽ отправляет заявку, а не списывает деньги.

## Запуск локально

Нужны Node.js 24 и доступный PostgreSQL 17. Скопируйте `.env.example` в `.env.local`, укажите пароль базы, секрет Better Auth длиной от 32 символов и `BETTER_AUTH_URL=http://localhost:3000`. Для локального подключения база обычно указывается как `postgresql://portfolio:<пароль>@127.0.0.1:5432/portfolio`.

```powershell
pnpm install
pnpm db:migrate
pnpm dev
```

## Подготовка на собственном сервере

1. Установите Docker Engine с Compose и настройте домен с HTTPS reverse proxy на порт `3000`.
2. Скопируйте `.env.example` в `.env`; задайте длинный уникальный `POSTGRES_PASSWORD`, случайный `BETTER_AUTH_SECRET` (минимум 32 символа) и `BETTER_AUTH_URL=https://ваш-домен`.
3. Установите в `DATABASE_URL` тот же пароль базы, например `postgresql://portfolio:<пароль>@db:5432/portfolio`.
4. Запустите `docker compose up --build -d`. Compose дождётся готовности PostgreSQL, создаст таблицы аутентификации и заявок, затем запустит сайт.
5. Создайте администратора. Команда запросит пароль интерактивно:

   ```sh
   docker compose exec web pnpm exec auth create-admin --email you@example.com --name "Имя автора" --role admin
   ```

6. Войдите через `/auth`, откройте `/admin` и проверьте тестовую заявку перед публикацией.

Смените секреты-примеры до запуска. Не добавляйте `.env` и содержимое `assets/photos` в публичный репозиторий; сайт использует только выбранные копии из `public/images`.

## Проверки

`pnpm typecheck`, `pnpm build`; проверьте главную страницу, `/auth` и `/privacy` на локальном сервере. Для проверки регистрации, заявок и админ-панели должна быть доступна PostgreSQL-база с применёнными миграциями.

## Telegram-уведомления о заявках

Форма сначала сохраняет заявку в PostgreSQL, затем при отдельном согласии отправляет её копию в Telegram. В `.env` задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Перед этим владелец должен открыть своего бота и нажать Start, чтобы бот мог отправлять ему сообщения. Если Telegram недоступен, запись в базе сохраняется, а статус доставки виден в админ-панели.

Не добавляйте `.env`, токен Telegram, пароль базы или другие секреты в GitHub. Перед включением формы на публичном сервере выберите сервер с базой данных в Российской Федерации, заполните сроки хранения и проверьте актуальные требования к передаче заявок в Telegram.
